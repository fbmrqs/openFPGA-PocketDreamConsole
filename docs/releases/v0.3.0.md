# Pocket Dream Console 0.3.0

First release prepared for GitHub: one native FPGA core for PDC30 Pink, PDC50,
PDC100, TMNT, Oui-Oui, Dora and VideoJet TV Games 1–4. All ten profiles have
user-confirmed Pocket gameplay. Full-speed audio/video, corrected sprite
priority, black startup, global A/B routing and sixteen display filters are
included. The reported musical-lead wobble was addressed through mixer and
scheduler throughput changes, followed by full scene comparisons and device
confirmation.

Download the installable `fbmrqs.PocketDreamConsole_0.3.0_2026-10-15.zip` asset,
merge `Assets`, `Cores` and `Platforms` into your card, and supply your own dumps
using the repository's ROM import guide. **No ROMs or BIOS are included.** The
entry is `fbmrqs.PocketDreamConsole`. Its production settings omit debug codes.

Save states, sleep/resume, Dock output, PDC200 and the Touch models are not
supported. Testing used Pocket firmware 2.7. Ten profile confirmations do not
establish exhaustive coverage of every minigame or cycle-perfect chip behavior.

The hardware bitstream is unchanged from the device-confirmed source `3d287a2`.
All four timing corners and source-bound component/original-ROM/music/library
checks passed. The supplied checksums and build information identify the binary
and packaging commit separately. Notices are included under the core directory.

The repository/release are staged privately; pupdate listing and public
announcement are pending. Source code uses ISC with third-party exceptions
documented in NOTICE.md. Development used OpenAI Codex.
