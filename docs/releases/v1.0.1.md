# Pocket Dream Console 1.0.1

ROM preparation is now available as a shared updater plugin. Put supported raw dumps or ZIPs in `Assets/pdc/import/`, then run the plugin. It identifies the dump, uses the right filename, trims or pads it where needed, and verifies the result. No Python or manual conversion is required. Original files are preserved.

In particular, the supported 128 MiB PDC100 dump becomes the required 64 MiB `pdc100.rom`. Renaming the raw dump alone can cause the “file too large” error.

- [Install the plugin](https://github.com/fbmrqs/openFPGA-PocketDreamConsole-plugin)
- [Preparation guide and supported dumps](https://github.com/fbmrqs/openFPGA-PocketDreamConsole/blob/v1.0.1/docs/roms.md)

This core package adds the plugin recommendation for pupdate/Pocket Sync. Existing users may need to install the plugin manually from their updater's Plugins page. In pupdate, enable its run-on-update option once to prepare new inputs automatically during Update All. Removing unfinished imports still asks for confirmation.

The FPGA binary, ROM loader, controls, display modes and game compatibility are unchanged from v1.0.0. This is a packaging and usability update; it does not add save states or sleep/resume. No ROMs are included or downloaded.
